# AI-Career-Navigator-Personalized-Learning-Roadmap-Generator
AI Learning Navigator 🎓 A local-first tutor using Ollama (Llama 3.2) and Streamlit. It generates custom 6-week roadmaps, interactive quizzes, and suggests curated resources—all running 100% locally for total privacy and zero API costs. The ultimate private AI roadmap generator. 🚀
